# План реализации страницы новелы (`frontend`, Vue 3 + TailwindCSS)

## Цель
Сделать страницу отдельной новелы со структурой:
1. Слева — обложка новелы.
2. Под обложкой:
   - зеленый dropdown выбора закладки (общий reusable-компонент),
   - кнопка **Читать / Продолжить чтение**,
   - статус новелы и год выпуска.
3. Справа — основной контент с верхней панелью переключения:
   - вкладка **Описание**,
   - вкладка **Главы**.
4. Вкладка **Описание**:
   - над текстом описания показать теги, жанры, переводчиков,
   - под описанием — секция комментариев.

## Подход (по конституции проекта)
1. Компонентная архитектура + максимум переиспользования из `shared`.
2. Mobile-first адаптив: на мобиле обложка и кнопки идут сверху, вкладки и контент ниже.
3. Общий dropdown для закладок делаем как `shared`-компонент для будущих страниц.
4. Состояния UI обязательны: empty/loading/error, hover/focus/active.

## Модель данных страницы новелы
Новела:
- `id`, `title`, `coverUrl`, `coverStyle`
- `status`, `releaseYear`
- `description`
- `genres: []`, `tags: []`, `translators: []`
- `chapters: []`
- `comments: []`
- `readingState` (new / reading)

UI-состояние:
- `activeTab` (`description` / `chapters`)
- `selectedBookmarkId`
- `isReadingStarted` (для текста кнопки: Читать / Продолжить чтение)

## Поведение
1. Кнопка чтения:
   - если пользователь еще не читал — «Читать»,
   - если есть прогресс — «Продолжить чтение».
2. Dropdown закладок:
   - зеленый стиль,
   - выбор закладки для добавления новелы,
   - универсальный API для повторного использования.
3. Вкладка «Описание»:
   - сначала чипы тегов/жанров/переводчиков,
   - затем текст описания,
   - затем комментарии.
4. Вкладка «Главы»:
   - список глав (дата/номер/название по данным).

## План по шагам
1. **Маршрут и каркас страницы**
   - Добавить `NovelView` в роутер (динамический путь по id/slugs).
   - Собрать двуколоночный layout (desktop) с mobile fallback.

2. **Общий dropdown**
   - Реализовать `AppSelect` в `shared` с акцентным зеленым стилем.
   - Подключить в сайдбар новелы под обложкой.

3. **Сайдбар новелы**
   - Обложка, select закладки, кнопка чтения, статус и год.
   - Стабильные размеры обложки и корректная адаптивность.

4. **Табы и контент справа**
   - `NovelTabs` + переключение между «Описание» и «Главы».
   - В «Описание» вывести мета-чипы и текст.
   - Под описанием подключить блок комментариев.

5. **Данные и composable**
   - Добавить мок `novelPageData.js`.
   - В `useNovelPage` собрать вычисления/действия: текущая вкладка, выбранная закладка, CTA чтения.

6. **Адаптив**
   - Mobile: вертикальный порядок (обложка → действия → табы → контент).
   - Desktop: 2 колонки, правая часть приоритетна по ширине.

7. **Тесты**
   - Unit: `useNovelPage` (переключение tab, текст CTA, select state).
   - Component: рендер вкладок, переключение контента, отображение комментариев в описании.
   - Component: работа `AppSelect` и событие выбора закладки.

## UX-заметки
- Вкладки должны быть заметно активны (контраст и состояние фокуса).
- Комментарии в описании отделить визуальным блоком/заголовком.
- В чипах метаданных поддержать перенос строк без поломки layout.
